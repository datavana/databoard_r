# Package index

## Login

Functions to login and logout to the databoard.

- [`da_login()`](https://datavana.github.io/databoard_r/reference/da_login.md)
  : Login to the Databoard service
- [`da_logout()`](https://datavana.github.io/databoard_r/reference/da_logout.md)
  : Log out from the Databoard service

## Main functionalities

Main functionalities to code, summarize and annotate text.

- [`llm_annotate()`](https://datavana.github.io/databoard_r/reference/llm_annotate.md)
  : Automated annotation with an LLM
- [`llm_code()`](https://datavana.github.io/databoard_r/reference/llm_code.md)
  : Automated content coding with an LLM
- [`llm_summarize()`](https://datavana.github.io/databoard_r/reference/llm_summarize.md)
  : Automated content summarisation with an LLM

## Customizable Functions

Functions with full customazibility.

- [`llm_prompt()`](https://datavana.github.io/databoard_r/reference/llm_prompt.md)
  : Prompt an LLM with custom prompts

## Helper Functions

Individual functions tp submit data to the databoard, fetch results and
show the progress.

- [`da_submit()`](https://datavana.github.io/databoard_r/reference/da_submit.md)
  : Submit tasks to the Databoard service
- [`da_fetch()`](https://datavana.github.io/databoard_r/reference/da_fetch.md)
  : Fetch results for previously submitted tasks
- [`da_finished()`](https://datavana.github.io/databoard_r/reference/da_finished.md)
  : Check whether all tasks have finished
- [`da_progress()`](https://datavana.github.io/databoard_r/reference/da_progress.md)
  : Summarise task states of a Databoard data frame
- [`da_request()`](https://datavana.github.io/databoard_r/reference/da_request.md)
  : Send a request to the databoard server
